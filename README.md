# CH32H417 引脚配置

一个类似 STM32CubeMX 引脚页的网页工具，用于沁恒 **CH32H417QEU6（QFN128）** 的引脚复用规划。作者：徐靖晨（[Funtaser](https://github.com/Funtaser)），中北大学 Epoch 竞技机器人战队。

在线使用：<https://funtaser.github.io/ch32h417-pins/> 。也可以下载 `index.html` 双击离线使用（单文件，无外部依赖）。

## 功能

- **引脚图：** QFN128 封装俯视图，128 个脚、95 个 IO，按分配状态着色，可标出 VIO18 供电脚和 5V 容忍脚。
- **按外设选引脚：** 左侧按外设分组列出全部复用信号（CAN、USART、SPI、I2C、定时器、ADC、FSMC/SDRAM、LTDC、以太网等），下拉选择候选引脚，候选顺序就是手册规定的输入优先级。
- **检查：** 同一信号分配到多个脚、违反数据手册第 2.3 节的输入优先级规则、手册两张表说法不一致、SWD 下载脚被占用、各供电域（VDD33 / VDDIO / VIO18）电压提醒、PC13–PC15 驱动能力限制、CAN 滤波器共用等。
- **生成代码（实验功能）：** 按沁恒标准外设库（`ch32h417_gpio.h` / `ch32h417_rcc.h`）生成 `Pins_Init()`，包括时钟使能、`GPIO_PinAFConfig` 和 `GPIO_Init`。写法已对照官方 EVT 例程（CAN、USART、SPI、I2C、TIM、ADC、DAC、OPA），但**未在芯片上编译运行验证**。
- **导入/导出：** 配置以 JSON 文本导入导出，方便队员之间共享。配置自动保存在本机浏览器。

## 数据来源与核对

- 引脚和复用数据解析自《CH32H417、H416、H415 数据手册》V1.9（CH32H417DS0）第 2.2 节引脚定义表（表 2-1-1）和第 2.3 节复用功能表（表 2-2-x），供电域取自第 1.4.45 节。
- 两张表中的 900 多个“信号 + 引脚 + AF 编号”组合已用脚本逐一互相比对，并把页面中全部 933 个可选组合逐个配置测试过。
- 中文版与英文版 V1.9 已对照，下列问题两版一致，不是翻译造成的。

### 发现的数据手册问题

页码为数据手册 V1.9 页脚页码（英文版 / 中文版）。

| # | 问题 | 引脚定义表 | 复用功能表等 | 结论 |
|---|---|---|---|---|
| 1 | SerDes 收发方向相反 | p31 / p25：PE3=TXP、PE4=TXN、PE5=RXP、PE6=RXN（引脚图 p26–27 / p21–22 相同） | 表 2-2-20，p77 / p68：PE3=RXP、PE4=RXN、PE5=TXP、PE6=TXN | **待沁恒确认** |
| 2 | PC1 的 SAI_SD_A | p33 / p27：AF7（同一格还有 PIOC_IO0(AF7)） | 表 2-2-27，p80 / p71：AF6 | 官方例程 SAI_Play 用 AF6，引脚定义表应为笔误 |
| 3 | PA15 的 LTDC_B4 | p42 / p36：AF10 | LTDC 表，p81 / p72：候选中没有 PA15 | 未确定，建议避开 |
| 4 | PC13 的 RTC | p32 / p25：RTC(AF1) | 第 2.3 节无对应表；参考手册 V1.8 表 9-26 写“硬件自动设置” | RTC 输出不需配置 AF1 |
| 5 | PC6 的 SWPMI | p40 / p34：SWPMI_IO | 表 2-2-26，p80 / p71：单线模式下 PC6 兼作 RX/TX | 不矛盾 |
| 6 | RGMII 接收数据线命名 | p40 / p34：RGMII_RXD0–3 | p79 / p70：RGMII_RD0–3 | 仅命名不同 |

页面会对第 1–3 条给出警告。

## 局限

- 只覆盖 QFN128 封装的引脚层：不含时钟树、外设参数（波特率、PWM 频率等）和中间件配置。
- UHSIF、SDMMC 通过重映射位而不是 AF 编号选择引脚，暂未收录。
- VIO18 域引脚上电默认 1.8V，需在硬件上把 VIO18 接到 VDDIO 或用 PWR_CTLR 配置电压，页面只做提醒。
- A 版芯片 CAN 不支持硬件过滤，请参照官方例程使用软件过滤。
